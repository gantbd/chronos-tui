# Security policy

Report suspected vulnerabilities privately to the repository owner. Keep
workspace paths, task content, socket locators, and credentials out of reports
posted publicly.

Chronos TUI is a local client. Chronos authorizes task mutations, Moira
authorizes receipt disclosure, and Daimon authorizes execution inspection.
Workstream names, task references, and execution IDs select records. The
handoff host owns source capture, destination authorization, and review.

The local deployment relies on private Unix endpoints and trusted host
configuration. Release qualification must cover stale selections, uncertain
effects, terminal rendering, dependency provenance, and receipt disclosure.
